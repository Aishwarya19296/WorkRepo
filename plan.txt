3. API Testing
Automate APIs for:

User registration/login
Authentication/token generation
Product search
Add/update/delete cart
Order creation
Order status

You can use requests or httpx.

5. Git

Create a proper Git repository with:

main
 └── develop
      ├── feature/api-tests
      ├── feature/ui-tests
      └── feature/reporting

Demonstrate meaningful commits and pull requests.

Set up GitHub Actions or Jenkins:

   ↓
Install dependencies
   ↓
Run API tests

   ↓

   ↓
Publish test results

7. Docker

Create a Dockerfile so someone can run your framework without manually configuring Python/dependencies.

For example:

docker build -t automation-framework .
docker run automation-framework

8. Linux

Run the framework on a Linux environment/server:

git clone <repository>
cd automation-framework

python -m venv venv
source venv/bin/activate

pip install -r requirements.txt

pytest
